# Bundled knowledge

This public distribution includes eight project-authored Markdown guides under `curated/`. Their stable document IDs and paths are listed in `manifest.json`.

Official WaveMetrics manuals and the image assets extracted from them are not included. If you already have an authorized knowledge bundle compatible with this server, set `IGOR_KNOWLEDGE_DIR` to the directory containing its `manifest.json`; otherwise `query_igor_help` has no bundled manuals to search. See the project [README](../README.md) for setup and official documentation links.
